Painel Informativo UNEB

Um projeto de painel digital para apresentar informações relevantes dos cursos e produções acadêmicas da Universidade do Estado da Bahia em monitores verticais.

🛠️ Arquitetura do Sistema

Explore os componentes que formam o projeto clicando nas abas abaixo.

Hardware

Tecnologia / Abordagem:

3x Raspberry Pi 4, 6x Monitores, Cabos Micro-HDMI.

Arquivos Relevantes:

N/A (Configuração física).

Painel Admin

Tecnologia / Abordagem:

Aplicação React para gerenciamento de conteúdo rodando em um servidor web central.

Arquivos Relevantes:

frontend/src/pages/Dashboard.jsx
frontend/src/components/admin/forms/ContentForm.jsx
frontend/src/services/playlistService.js

Backend

Tecnologia / Abordagem:

API em PHP que gerencia o `playlist.json` via FTP ou localmente.

Arquivos Relevantes:

server/api/handle_login.php
server/api/get_content.php
server/api/manage_playlist.php

Exibição (Cliente)

Tecnologia / Abordagem:

3x Raspberry Pis, cada um com 2 navegadores em modo kiosk (tela cheia).

Arquivos Relevantes:

clients/playlist-viewer/index.js
clients/tcc-viewer/script.js

Comunicação

Tecnologia / Abordagem:

Todos os Pis buscam dados do mesmo endpoint (`get_content.php`) na rede local.

Arquivos Relevantes:

server/api/get_content.php

Sincronização

Tecnologia / Abordagem:

Atualização do `playlist.json` central e recarregamento periódico pelos clientes.

Arquivos Relevantes:

clients/playlist-viewer/index.js (setInterval)
server/api/manage_playlist.php

Como Executar (Dev)

# 1. Clone o repositório
git clone https://github.com/seu-usuario/painel-informativo-uneb.git

# 2. Acesse o diretório
cd painel-informativo-uneb

# 3. Rode o frontend
cd frontend
npm install
npm run dev

# 4. Configure o backend em um servidor
# (XAMPP, WAMP, etc.) apontando para
# a pasta /server/public do projeto.
